# _forAI Guide

## 한 줄 요약

이 디렉터리는 vla_curriculum 작업을 이어받을 때 필요한 AI 작업 문맥을 정리해 두는 곳이다.

## 읽는 순서

1. readme.md
2. inventory.md
3. memo.md
4. plan.md
5. dev_log.md

## 문서 역할

- inventory.md: 저장소에 실제로 있는 구조, 엔트리포인트, 빌드/검증 명령을 기록한다.
- plan.md: 앞으로 진행할 개발 계획과 우선순위만 기록한다.
- memo.md: 프로토콜, 기본값, 디버깅 교훈 같은 참고 메모를 모은다.
- dev_log.md: 날짜별 작업 이력과 _forAI 정리 내역을 남긴다.

## 현재 스냅샷

- 저장소 경로: E:/work/plan_lecture/vla_curriculum
- 대상 보드/플랫폼: LeRobot SO101
- 현재 버전: 커리큘럼 문서 초안 운영 중
- 메인 엔트리포인트: readme.md

## 유지 규칙

- 계획이 아닌 참고 정보는 plan.md가 아니라 memo.md에 둔다.
- 저장소 구조나 실행 명령이 바뀌면 inventory.md를 먼저 갱신한다.
- 작업 이력은 날짜를 붙여 dev_log.md에만 남긴다.
- 새 작업을 시작할 때는 inventory.md와 memo.md를 먼저 읽고, 실제 할 일은 plan.md에서 확인한다.
