# Plan

## Current goal

- 기존 `readme.md`, `basic_curriculum.md`, `intermediate_curriculum.md` 흐름을 유지하면서 온라인 전용 커리큘럼 초안을 추가한다.
- 온라인 트랙은 실물 SO101 실습 의존도를 낮추되, 설명의 기준선은 `LeRobot`와 `SO101` 태스크 맥락에 둔다.
- 강의 순서는 `LeRobot -> Isaac Sim -> Omniverse/USD 최소 개념`이 아니라, `LeRobot -> Isaac Sim 실습`을 메인으로 두고 `Omniverse/USD`는 필요한 만큼만 내장해 설명한다.
- 총 35강, 차시당 약 20분 기준으로 운영 가능한 분량을 먼저 확정한다.
- 기존 초급/중급을 대체하는 문서가 아니라, 별도 온라인 트랙 문서로 정리하는 방향을 우선 검토한다.

## Scope

- 포함: 온라인 트랙의 대상, 목표, 선수지식, 모듈 구조, 차시 배분, 실습 시나리오 설계
- 포함: 기존 문서와 용어, 산출물, 평가 기준의 정합성 유지
- 제외: 고급 연구 트랙 통합, 실제 실습 코드 구현, 설치 자동화 문서 작성

## Priority

- `P1`: 온라인 트랙의 기준 서사를 `LeRobot/SO101` 중심으로 확정
- `P2`: 35강 기준 모듈 구성과 `LeRobot -> Isaac Sim` 흐름 설계
- `P3`: 각 모듈의 실습 태스크, 산출물, 평가 방식 정의
- `P4`: 별도 온라인 커리큘럼 문서 초안 작성 및 메인 문서 반영 범위 결정

## Key decisions to validate

- 온라인 트랙의 첫 설명 단위를 `도구 소개`가 아니라 `LeRobot 파이프라인과 SO101 태스크 맥락`으로 고정할지 확정
- `Isaac Sim` 실습을 `SO101` 맥락의 미러 태스크로 설계할지, 일반 pick-and-place 시뮬레이션으로 넓힐지 확정
- `Omniverse/USD`를 독립 모듈로 분리하지 않고 `Isaac Sim` 입문 안에 최소 개념만 포함하는 방향이 적절한지 검증
- 학습자 PC 성능 제약을 고려해 직접 실습 중심으로 갈지, 시연 + 과제 혼합형으로 갈지 정리
- 35강 x 20분 구성이 실습 리뷰와 최종 프로젝트까지 담기에 충분한지 검토

## Proposed structure

- 모듈 1: 온라인 트랙 소개와 `LeRobot` 전체 파이프라인 이해 `4강`
- 모듈 2: `SO101` 태스크 맥락, 데이터 수집, 평가 기준 이해 `6강`
- 모듈 3: `Isaac Sim` 설치, 기본 조작, 씬 이해 `7강`
- 모듈 4: 로봇 태스크 구성, 카메라/센서, 미러 실습 설계 `8강`
- 모듈 5: 시뮬레이션 데이터 기록, 태스크 평가, 결과 해석 `6강`
- 모듈 6: 미니 프로젝트, 결과 정리, 발표 `4강`

## Structure notes

- `Omniverse`는 독립 대주제로 세우지 않고, `Isaac Sim`을 이해하는 데 필요한 `USD`, stage, asset, extension 수준만 포함한다.
- 실습 설명의 출발점은 툴 기능이 아니라 `LeRobot`의 데이터 수집 -> 실행 -> 평가 흐름으로 잡는다.
- 시뮬레이터 실습도 가능하면 `SO101`과 동일한 태스크 언어를 유지해 기존 초급/중급 문서와 연결한다.

## Work plan

1. 기존 초급/중급 문서에서 재사용할 학습 목표, 산출물, 평가 용어를 추출한다.
2. 온라인 트랙의 대상 학습자와 선수지식을 한 문장 수준으로 명확히 정리한다.
3. `LeRobot` 파이프라인을 온라인 환경에서 어떻게 설명할지 먼저 정리하고, 그 뒤 `Isaac Sim` 미러 실습으로 연결한다.
4. `Omniverse/USD` 개념 중 필수 항목만 추려 `Isaac Sim` 모듈 안에 배치한다.
5. 35강 분량을 모듈별로 재배치하고 각 강의의 핵심 실습 태스크를 붙인다.
6. 온라인 전용 문서 초안을 작성하고 `readme.md`에 연결 위치를 결정한다.

## Risks

- `LeRobot`를 먼저 설명하더라도 실물 장비 경험이 없으면 학습자에게 추상적으로 느껴질 수 있다.
- 온라인 과정이라도 GPU와 설치 부담이 크면 접근성 목표와 충돌할 수 있다.
- `Omniverse` 개념 설명이 과해지면 다시 도구 중심 강의로 쏠릴 수 있다.
- 실로봇 경험 없이 시뮬레이터만으로 진행하면 SO101 중심 서사가 약해질 수 있다.
- 기존 초급/중급 문서와 평가 기준이 분리되면 저장소 전체 일관성이 깨질 수 있다.
