# Memo

## 제품 기준선

- 플랫폼: LeRobot SO101
- 운영 OS 권장: Ubuntu 22.04
- 개발 환경: Python (venv 또는 conda)
- 문서 기준일: 2026-04-17

## 기본 설정값

- 공통 실습 태스크: 단일 물체 집기, 위치 이동, 간단 pick-and-place
- 공통 산출물: 데이터셋, 학습 로그, 평가 기록, 데모 영상
- 초급 기간: 6주
- 중급 기간: 8주
- 온라인 트랙 분량: 35강, 차시당 약 20분

## 런타임 구조 메모

- 초급: 실로봇 bring-up -> teleoperation -> 데이터 수집 -> 기본 모델 실행
- 중급: 태스크 재정의 -> 데이터 품질관리 -> 학습/평가 -> 시뮬레이터 확장
- 온라인: LeRobot 파이프라인 이해 -> SO101 태스크 해석 -> Isaac Sim 미러 실습 -> 평가/프로젝트

## 동작 규칙

- LeRobot first: 설치/수집/학습/평가 흐름을 LeRobot 기준으로 유지
- SO101 one-platform: 트랙 간 하드웨어 기준을 통일
- Real robot first: 초급은 실로봇 중심으로 운영
- Online sim support: 온라인 트랙은 `Isaac Sim`을 메인으로 쓰되 `Omniverse/USD`는 최소 개념만 포함

## 반복 금지

- 고급 연구 주제를 초급/중급 본과정에 과도하게 혼합하지 않는다.
- 평가 기준 없이 데이터만 수집하는 운영을 반복하지 않는다.
- 문서 간 용어(트랙명, 산출물명, 평가항목) 불일치를 방치하지 않는다.
