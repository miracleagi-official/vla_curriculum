# Module 06. Omniverse와 Isaac Sim 활용 넓히기

## 범위

- 차시: `32-35강`
- 역할: Omniverse와 Isaac Sim이 어디까지 확장될 수 있는지 쉬운 예시로 이해하게 한다.

## 현재 포함 차시

- 32강: Omniverse는 Isaac Sim과 어떤 관계일까
- 33강: 만든 장면과 물체를 다시 써보기
- 34강: 센서와 여러 조건 바꾸기 응용 보기
- 35강: 앞으로 무엇을 더 해볼 수 있을까

## 이후 상세화 항목

- Omniverse/Isaac Sim 관계 설명 자료
- 장면 재사용 예시
- 응용 사례 정리 방식
- 다음 단계 학습 가이드
- 초급/중급 실로봇 과정 연결 메모

## 메모

- 어렵게 들어가기보다 “어디에 쓸 수 있나” 중심으로 보여주는 편이 낫다.
- 과정 마지막에는 초급/중급 실로봇 과정이나 더 깊은 Isaac Sim 학습으로 어떻게 이어질지 정리한다.
