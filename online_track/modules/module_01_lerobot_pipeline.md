# Module 01. 수업 소개와 LeRobot 흐름 보기

## 모듈 한눈에 보기

- 차시: `1-3강`
- 역할: 이 수업이 어떤 수업인지 먼저 설명하고, LeRobot 전체 흐름을 쉽게 잡게 한다.
- 핵심 기준: 도구 설명보다 먼저 `LeRobot -> 데이터 -> 실행 -> 평가` 흐름을 이해하게 한다.
- 모듈 산출물: 학습 로드맵 메모, 파이프라인 한 장 요약, 실습 기대치 메모

## 모듈 목표

이 모듈이 끝나면 학습자는 다음을 할 수 있어야 한다.

1. 이 온라인 수업이 초급/중급 실로봇 과정과 어떻게 다른지 설명할 수 있다.
2. LeRobot과 SO101이 수업 전체에서 어떤 역할을 하는지 큰 흐름으로 말할 수 있다.
3. 왜 온라인 과정에서 시뮬레이션을 쓰는지, 어디까지 가능한지 이해할 수 있다.
4. 이 수업이 어떻게 진행되는지 이해하고 이후 차시를 따라갈 준비를 마칠 수 있다.

## 강의 운영 기준

- 권장 길이: 차시당 `20분`
- 권장 구성: 도입 `3분` -> 핵심 설명 `10분` -> 예시/데모 `5분` -> 정리/과제 `2분`
- 설명 톤: 전문 용어를 바로 던지지 말고, 먼저 쉬운 말로 설명한 뒤 필요한 용어만 붙인다.
- 강의 방식: 시연형 학습자와 실습형 학습자 모두 따라올 수 있도록 화면 예시와 체크리스트를 같이 준다.

## 차시 요약표

| 차시 | 한 줄 목표 | 핵심 질문 | 결과물 |
|---|---|---|---|
| 1강 | 수업의 성격과 진행 방식을 이해한다. | 이 수업은 누구를 위한 수업이고, 어떻게 진행되는가? | 학습 목표 3줄 |
| 2강 | LeRobot 전체 흐름을 큰 그림으로 본다. | 로봇 AI 실습은 어떤 순서로 진행되는가? | 파이프라인 한 장 요약 |
| 3강 | 시뮬레이션을 쓰는 이유와 한계를 안다. | 왜 실로봇 대신 시뮬레이터를 쓰는가? | 실습 기대치 메모 |

## 차시별 상세 강의안

### 1강. 이 수업은 어떤 수업이고 어떻게 진행되는가

#### 수업 목표

- 이 온라인 수업의 목적을 한 문장으로 말할 수 있다.
- 초급/중급 실로봇 과정과 온라인 과정의 차이를 구분할 수 있다.
- 수업 진행 방식, 준비물, 최종 산출물을 이해할 수 있다.

#### 꼭 전달할 메시지

- 이 수업은 실로봇 조작 수업이 아니라, **LeRobot 흐름과 시뮬레이션 실습 감각을 익히는 수업**이다.
- 온라인 트랙은 초급/중급을 대신하는 과정이 아니라, **장비 제약을 보완하는 학습 경로**다.
- 결과물은 “완벽한 실행”보다 **흐름을 이해하고 정리한 문서**가 더 중요하다.
- 이 차시에서 수업 진행 방식과 준비물을 같이 설명하고 넘어간다.

#### 20분 진행안

| 시간 | 진행 내용 | 진행 방식 | 강사용 메모 |
|---|---|---|---|
| 0-3분 | 인사, 수업 목표, 오늘 배울 내용 소개 | 브리핑 | 첫 문장에서 “이 수업은 무엇을 하는 수업인가”를 바로 말한다. |
| 3-7분 | 전체 트랙 구조 설명 | 슬라이드 | 초급, 중급, 온라인 트랙의 차이를 표로 보여주면 이해가 빠르다. |
| 7-10분 | 온라인 트랙이 필요한 이유 설명 | 예시 설명 | 장비 없음, 시간 제약, GPU 환경 차이 같은 현실적 이유를 든다. |
| 10-13분 | 수업 진행 방식과 준비물 안내 | 안내 | 이후 차시 운영 방식, 과제 제출 방식, 공통 준비물을 짧게 정리한다. |
| 13-17분 | 최종 산출물 소개 | 화면 예시 | 태스크 정의서, 체크리스트, 결과 요약서 같은 문서형 산출물을 먼저 보여준다. |
| 17-19분 | 학습자에게 기대하는 태도 설명 | 안내 | “완벽히 실행”보다 “왜 이렇게 되는지 이해하고 정리”가 중요하다고 못 박는다. |
| 19-20분 | 오늘 과제 안내와 마무리 | 정리 | 학습 목표 3줄 과제는 너무 길지 않게 적게 한다. |

#### 준비 자료

- 전체 커리큘럼 구조 1장
- 초급/중급/온라인 트랙 비교표 1장
- 수업 진행 방식 요약표 1장
- 최종 산출물 예시 화면 1장

#### 과제

- `개인 학습 목표 3줄 작성`
- 형식:
  - 왜 이 수업을 듣는가
  - 무엇을 배우고 싶은가
  - 수업이 끝났을 때 무엇을 남기고 싶은가

#### 체크포인트

- 학습자가 “온라인 과정이니까 실습이 거의 없다”라고 오해하지 않게 한다.
- 반대로 “실로봇 과정과 완전히 같다”라고 기대하지 않게 선을 분명히 긋는다.
- 진행 방식 설명이 길어져서 별도 차시처럼 느껴지지 않게 한다.

### 2강. LeRobot과 SO101 전체 흐름 한눈에 보기

#### 수업 목표

- LeRobot, SO101, dataset, 실행, 평가가 어떤 순서로 연결되는지 설명할 수 있다.
- “수집 -> 실행 -> 평가” 흐름을 한 장 그림으로 정리할 수 있다.

#### 꼭 전달할 메시지

- 로봇 AI 실습은 복잡해 보여도 결국 **태스크 정하기 -> 데이터 모으기 -> 실행해 보기 -> 결과 확인하기** 흐름이다.
- LeRobot은 이 흐름을 실제로 다룰 수 있게 해주는 기준 도구다.
- 온라인 과정에서도 이 큰 흐름은 그대로 유지된다.

#### 20분 진행안

| 시간 | 진행 내용 | 진행 방식 | 강사용 메모 |
|---|---|---|---|
| 0-2분 | 지난 시간 짧은 복습 | 브리핑 | 온라인 트랙의 목적을 한 번 더 짚는다. |
| 2-6분 | SO101이 무엇인지 소개 | 슬라이드 + 이미지 | follower/leader 이미지가 있으면 같이 보여준다. |
| 6-10분 | LeRobot 전체 흐름 설명 | 슬라이드 | 태스크 -> 데이터 -> 실행 -> 평가 순서를 크게 반복한다. |
| 10-14분 | `lerobot-record`, dataset, 실행 로그의 역할 설명 | 예시 설명 | 처음부터 세부 명령어로 들어가지 말고 역할만 말한다. |
| 14-17분 | 온라인 과정에서 이 흐름이 어떻게 바뀌는지 설명 | 비교 설명 | 실로봇 대신 시뮬레이션 scene과 미러 태스크가 들어온다고 설명한다. |
| 17-20분 | 파이프라인 한 장 요약 과제 안내 | 정리 | 화살표 4~5개 정도만 있어도 충분하다고 안내한다. |

#### 준비 자료

- SO101 이미지
- LeRobot 전체 흐름 슬라이드
- dataset/실행/평가 예시 화면

#### 과제

- `파이프라인 한 장 요약`
- 형식:
  - A4 1장 또는 메모 1장
  - 반드시 들어갈 요소: 태스크, 데이터, 실행, 평가
  - 그림이나 화살표 중심으로 간단히 정리

#### 체크포인트

- LeRobot을 “모델 하나”로 오해하지 않게 한다.
- 데이터 수집과 모델 실행을 같은 단계로 섞어 말하지 않게 한다.

### 3강. 왜 시뮬레이션을 쓰는가

#### 수업 목표

- 온라인 과정에서 시뮬레이션을 쓰는 이유를 2~3개 말할 수 있다.
- 시뮬레이션의 장점과 한계를 같이 설명할 수 있다.
- 실로봇과 시뮬레이션의 차이를 현실적으로 이해한다.

#### 꼭 전달할 메시지

- 시뮬레이션은 실로봇을 완전히 대체하는 도구가 아니라, **연습과 설계, 반복 실험에 강한 도구**다.
- 온라인 과정에서는 접근성과 반복성이 큰 장점이다.
- 다만 실제 하드웨어 감각, 오차, 세팅 이슈까지 완전히 대신하진 못한다.

#### 20분 진행안

| 시간 | 진행 내용 | 진행 방식 | 강사용 메모 |
|---|---|---|---|
| 0-3분 | 앞 시간 복습과 오늘 질문 제시 | 브리핑 | “왜 굳이 시뮬레이터를 쓸까?” 질문으로 시작한다. |
| 3-8분 | 시뮬레이션의 장점 설명 | 슬라이드 | 반복 실험, 안전성, 접근성, 장비 비용 절감 중심으로 말한다. |
| 8-12분 | 시뮬레이션의 한계 설명 | 비교 설명 | 마찰, 오차, 카메라 실제 노이즈, 조립 상태 차이를 예시로 든다. |
| 12-16분 | 실로봇 vs 시뮬레이션 비교 | 표 설명 | “무엇을 잘 가르치고 무엇은 덜 가르치는가”로 설명하면 쉽다. |
| 16-18분 | 온라인 과정에서 가능한 것/어려운 것 정리 | 정리 | scene 구성, 태스크 설계, 평가표 작성은 가능하다고 분명히 한다. |
| 18-20분 | 기대치 메모 과제 안내 | 마무리 | 할 수 있는 것 2개, 어려운 것 1개를 적게 한다. |

#### 준비 자료

- 실로봇 실습 사진 또는 이미지
- 시뮬레이션 화면 예시
- 장점/한계 비교표

#### 과제

- `실습 기대치 메모`
- 형식:
  - 시뮬레이션으로 할 수 있는 것 2가지
  - 시뮬레이션만으로 부족한 것 1가지
  - 내가 이 과정을 통해 얻고 싶은 것 1가지

#### 체크포인트

- 학습자가 시뮬레이터를 “가짜 실습”으로 보지 않게 한다.
- 반대로 시뮬레이터만으로 실로봇 감각까지 모두 익힐 수 있다고 과장하지 않는다.

## 모듈 산출물 정리

- 학습 목표 3줄 메모
- LeRobot 파이프라인 한 장 요약
- 실습 기대치 메모

## 강사용 운영 메모

- 모듈 1의 목적은 기술 설명이 아니라 **학습자 머릿속에 전체 지도 한 장을 만드는 것**이다.
- 억지로 차시를 늘리기보다 첫 차시에 진행 방식과 준비물을 같이 정리하고 바로 큰 흐름으로 넘어간다.
- 여기서 용어를 너무 많이 넣으면 다음 모듈 진입 전에 피로도가 높아진다.
- 매 시간 마지막 1분은 반드시 “오늘 배운 내용을 한 문장으로 다시 말하면?”으로 정리한다.
- 학습자 질문이 기술 세부사항으로 너무 빨리 들어가면 “그 내용은 모듈 3부터 본격적으로 다룬다”라고 선을 잡는다.

## 다음 모듈 연결

모듈 1이 끝나면 학습자는 “이 수업이 어떤 수업인지”와 “LeRobot 흐름이 어떻게 돌아가는지”를 이해한 상태가 된다. 다음 모듈에서는 이 흐름을 바탕으로 **SO101 태스크, 데이터 구조, 평가 기준**을 더 구체적으로 다룬다.
