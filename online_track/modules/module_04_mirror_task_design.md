# Module 04. 로봇이 움직일 연습 장면 만들기

## 범위

- 차시: `17-25강`
- 역할: SO101이 하던 일을 Isaac Sim 화면 안에서 비슷하게 따라 해 볼 장면으로 만든다.

## 현재 포함 차시

- 17강: 로봇 팔을 화면에 올리고 자리 잡기
- 18강: 작업대와 기준 위치 정하기
- 19강: 집을 물건과 도착 위치 만들기
- 20강: 카메라와 보는 위치 정하기
- 21강: 집고 옮기고 놓는 순서 짜기
- 22강: 부딪힘과 움직임 제한 살펴보기
- 23강: SO101 연습 장면 1차로 만들어보기
- 24강: 처음 실행해 보고 장면 점검하기
- 25강: 잘 안 되는 부분 다시 고치기

## 이후 상세화 항목

- 장면 구성 절차
- 좌표/카메라 기준값
- 실패 사례 예시
- 디버깅 체크리스트
- 모듈 산출물 제출 형식

## 메모

- 이 모듈부터 실제 결과물이 나오므로 파일/캡처 저장 규칙을 같이 정해야 한다.
- 억지로 앞단 차시를 늘리기보다, 여기서 1차 실행 점검 시간을 확보하는 편이 자연스럽다.
- 모듈 2의 태스크 정의서와 평가표를 기준 참조로 유지한다.
