# Module 02. SO101이 할 일과 기준 정하기

## 범위

- 차시: `4-9강`
- 역할: SO101이 어떤 일을 하게 할지 정하고, 그 결과를 어떻게 적고 판단할지 정리한다.

## 현재 포함 차시

- 4강: SO101으로 어떤 일을 하게 할까
- 5강: 로봇은 무엇을 보고 어떻게 움직일까
- 6강: 실습 기록은 어떻게 쌓일까
- 7강: 어디까지 하면 성공이고 무엇이 실패일까
- 8강: 결과를 어떤 기준으로 적고 비교할까
- 9강: 실제 로봇 일을 화면 안으로 옮기기

## 이후 상세화 항목

- 태스크 정의서 템플릿
- 평가표 템플릿
- 관측/행동 표준 용어
- 차시별 예시 장면
- 과제와 피드백 기준

## 메모

- 이후 모듈들이 모두 이 기준 문서를 참조하도록 구성한다.
- SO101 태스크 언어를 일반 시뮬레이션 설명보다 우선한다.
