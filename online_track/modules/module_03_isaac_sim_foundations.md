# Module 03. Isaac Sim으로 장면 만들기 기초

## 범위

- 차시: `10-16강`
- 역할: Isaac Sim에서 화면과 장면을 다루는 기본 방법을 익히게 한다.

## 현재 포함 차시

- 10강: Isaac Sim은 어떻게 실행하나
- 11강: 화면 구성을 먼저 익히기
- 12강: 장면 안 물체는 어떻게 정리될까
- 13강: 꼭 알아야 할 기본 개념만 익히기
- 14강: 필요한 물체와 기능 불러오기
- 15강: 움직임, 시간, 카메라 기본 익히기
- 16강: 첫 연습 장면 만들어보기

## 이후 상세화 항목

- 설치/실행 분기 시나리오
- UI 설명용 캡처 목록
- 기초 실습 절차
- 자주 막히는 지점과 대응
- 필수 용어 정리

## 메모

- `Omniverse`는 독립 입문 모듈이 아니라 Isaac Sim 문맥 안에서만 설명한다.
- GPU가 없는 학습자도 화면 기준으로 따라올 수 있게 시연형 경로를 병행한다.
