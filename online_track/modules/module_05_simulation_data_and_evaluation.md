# Module 05. 데이터셋 만들고 간단한 코드 써보기

## 범위

- 차시: `26-31강`
- 역할: 장면에서 나오는 정보를 데이터처럼 저장하고, 간단한 코드로 읽어보는 흐름을 익히게 한다.

## 현재 포함 차시

- 26강: 어떤 정보를 저장해야 데이터가 될까
- 27강: 데이터셋 폴더는 어떻게 생기게 할까
- 28강: 장면 정보를 코드로 읽어보기
- 29강: 여러 장면을 반복해서 저장해보기
- 30강: 만든 데이터를 열어보고 점검하기
- 31강: 이 데이터가 LeRobot 흐름에서 어떻게 쓰일까

## 이후 상세화 항목

- 저장 항목 예시
- 데이터셋 폴더 예시
- 간단한 Python 예제
- 데이터 점검표 양식
- 제출 예시 파일 구조

## 메모

- 이 모듈은 “데이터셋이 실제로 어떻게 만들어지는가”를 온라인 과정 안에서 가장 분명하게 보여주는 역할이 크다.
- 코드는 길게 가지 말고, 읽고 따라칠 수 있는 짧은 예제로 제한하는 편이 낫다.
- 모듈 6의 Omniverse/Isaac Sim 확장 이해와 자연스럽게 연결되도록 작성한다.
